# Крос-таби SPSS

Браузерний інструмент для побудови крос-табів із файлів SPSS (.sav / .zsav): таблиці з банером, значущість, модифіковані змінні, відкриті відповіді, експорт у Word, Excel, .sav та інтерактивний HTML-звіт.

Увесь інструмент — один файл `index.html`. Дані обробляються лише в браузері й нікуди не надсилаються.

Розгортається на Vercel автоматично з гілки `main`.
